---

## 📌 Project Overview

Financial fraud costs the global economy over $5 trillion annually. Traditional rule-based systems fail to adapt to evolving fraud patterns. **FraudShield AI** is a production-ready machine learning system that detects fraudulent transactions in real-time, explains every decision using SHAP values, and monitors model health using MLflow.
